# Data-Driven Real Estate Investment Decision Model under Uncertainty

A publication-quality quantitative finance project integrating machine learning, stochastic simulation, and leveraged real-estate valuation for investment decision support.

## Problem Statement
Real estate investments are exposed to nonlinear pricing dynamics and material uncertainty in financing conditions, rental performance, and terminal values. This project builds a rigorous decision framework to answer:

- What is a defensible fair-value estimate for a property given micro + macro features?
- What is the full distribution of investment outcomes (not only expected return)?
- Which assumptions (interest rates, purchase price, rental yield) drive economic viability most?

## Methodology

### 1) Data construction and feature engineering
- Built a synthetic panel-like dataset with 30,000 transactions (3,000 properties across 10 yearly observations).
- Embedded economically consistent structural relationships among:
  - Hedonic attributes (size, beds, baths, age),
  - Neighborhood quality (school/transit/crime),
  - Macro variables (mortgage rates, unemployment, inflation, GDP growth),
  - Time trend and cyclical housing dynamics.
- Engineered nonlinear and interaction features (log-size, age-squared, location composite, rent-to-price, size×school).

### 2) Price prediction via machine learning
- Trained and evaluated three models on out-of-sample data:
  - Linear Regression,
  - Random Forest Regressor,
  - Gradient Boosting Regressor.
- Evaluation metrics:
  - R² (in-sample and out-of-sample),
  - RMSE (in-sample and out-of-sample).
- Selected the best model by out-of-sample RMSE and analyzed feature contribution.

### 3) Financial model (levered investment)
- Implemented a full annual cash-flow engine including:
  - acquisition and closing costs,
  - debt financing with amortization,
  - vacancy and operating expenses,
  - rental growth,
  - terminal sale net of transaction costs and residual debt.
- Computed:
  - NPV,
  - IRR,
  - Payback period.

### 4) Monte Carlo risk modeling
- Simulated 12,000 scenarios of annual price growth and rental growth.
- Produced empirical distributions for IRR, NPV, terminal value, and downside probabilities.
- Estimated risk statistics including tail metrics (VaR/CVaR-style NPV diagnostics).

### 5) Sensitivity and scenario analysis
- Performed grid-based sensitivity analysis for:
  - interest rates,
  - purchase price,
  - annual rent (rental yield proxy).
- Built scenario analyses (Bear/Base/Bull) to compare median returns and probability of capital loss.

## Key Results (Typical Run)
- Tree-based models materially outperform linear baseline on out-of-sample fit.
- Return distributions show meaningful tail risk despite attractive median outcomes.
- Investment viability is highly sensitive to entry valuation and financing costs.

## Practical Insights
- Point forecasts are insufficient for real-estate capital allocation.
- Integrating ML valuation with Monte Carlo and structured cash-flow accounting gives a materially more robust decision process.
- The framework is production-extensible (regional segmentation, regime models, Bayesian uncertainty, transaction-cost microstructure).
